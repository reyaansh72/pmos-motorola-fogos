What we're building

Small steps. Real progress.

The groundwork is being developed in the open. Actual device functionality still needs to be verified on working hardware.

⌘

Kernel development

A downstream Motorola kernel fork, package configuration, kernel config work, and device-specific fixes.

▱

Device integration

Device metadata, initramfs module lists, boot settings, and the packaging needed to prepare a port.

◈

Mobile Linux

The goal is a usable postmarketOS experience, with a mobile-friendly Linux interface and hardware support.
