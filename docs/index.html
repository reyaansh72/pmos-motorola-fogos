So, what's the port working on?

The stock phone has the fun hardware; the Linux port has to teach each part how to talk to Linux. That means device setup, kernel bits, boot details, and plenty of careful testing.

Display, touch, Wi-Fi, audio, cameras, mobile data, and battery life all need real-device checks. Some will be easier than others (phones enjoy keeping secrets).

Quick answers

Curious? Start here.

The short version of the questions that tend to pop up first.

What is this project? +
It is an independent, community-driven postmarketOS port for the Motorola Moto G45 5G (codename fogos), aiming to bring a native Linux environment to the device.
Can I use this as my daily phone? +
Not yet. This is experimental porting work, not a daily-driver system. Display, connectivity, audio, and other hardware need real testing. Please don't risk your main phone on an unverified build.
What's a kernel, anyway? +
It's the layer that lets Linux talk to the phone's hardware. This project has a device-specific Linux 5.4 kernel tree for the SM6375 platform; having a kernel build does not mean all phone features work yet.
Do I need to be a Linux wizard to help? +
Nope! Clear docs, careful testing, useful issue reports, and code review all help. The Contribute page has a few ways to jump in.
